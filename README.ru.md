# Dog Walk

[English](README.md)

Нативный desktop-питомец AngelOS в духе Cat Walk. Пиксельная собака постоянно
ходит по виджету на рабочем столе, разворачивается у краёв, иногда засыпает и
реагирует на клик. Маленькая анимация собаки также показывается на панели.

## Использование

Установите плагин через Community Store, перезапустите AngelOS и добавьте его
через контекстное меню рабочего стола: **ПКМ по рабочему столу -> Вид -> Dog
Walk**. Виджет можно передвигать за заголовок окна. Размер, скорость, подпись и
сон настраиваются в **Настройки -> Плагины -> Dog Walk**.
