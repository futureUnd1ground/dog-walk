# Dog Walk

[English](README.md) | [Русский](README.ru.md)

Плагин AngelOS для учёта прогулки с собакой. В нём есть desktop-виджет и
кнопка на панели со стартом, паузой, продолжением и завершением прогулки.

Время сохраняется в настройках плагина. Дистанция рассчитывается примерно по
скорости 4,5 км/ч; GPS-трекинга нет. Внешние программы и сеть не требуются.

## Установка для разработки

Скопируйте каталог в пользовательские плагины AngelOS:

```bash
mkdir -p ~/.config/angelos/plugins
cp -a dog-walk ~/.config/angelos/plugins/dog-walk
angelos restart
```

Затем включите **Dog Walk** в **Settings -> Plugins** и добавьте desktop-виджет
или включите виджет панели.
